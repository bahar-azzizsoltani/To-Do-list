# Daily Tasks

## Project Overview
A Python desktop application for managing daily tasks through a graphical user interface.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete selected tasks.
- Clear all tasks with a confirmation prompt.
- Display task status and basic feedback messages.
- Navigate the task list using a scrollbar.

## Technologies
- Python
- Tkinter (`tkinter` and `tkinter.messagebox`)
